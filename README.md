# AWS Cloud Security Posture Assessment Lab

Self-directed cloud security lab built on the AWS Free Tier. I built an intentionally misconfigured environment, found the issues with AWS Security Hub, and documented how to fix them.

## What I did
- Created intentional misconfigurations across IAM, S3 and VPC
- Used AWS Security Hub (CSPM) to find 60+ issues
- Documented the fixes for the High and Medium severity findings in a security assessment report (IAM least privilege, blocking S3 public access, tightening VPC security groups)

## Tools used
AWS Security Hub, IAM, S3, VPC, EC2

## Skills shown
Cloud security posture management, least-privilege IAM, network segmentation, security reporting
